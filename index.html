Sin conexión

8 métricas de Intune que todo equipo debería seguir

El mismo marco de prioridades del informe de Defender, traducido a la gestión de dispositivos: una cifra de cabecera, una cola de prioridad real, un plan de remediación y dos chequeos de ritmo. Los datos salen directo de tu tenant vía Microsoft Graph.

Conecta tu tenant en 4 pasos

  1. En Microsoft Entra ID → Registros de aplicaciones, crea una app. En Autenticación añade una plataforma SPA (aplicación de página única) con esta URI de redirección:
    —
  2. En Permisos de API → Microsoft Graph → Delegados, agrega y concede consentimiento de administrador a:
    DeviceManagementManagedDevices.Read.All DeviceManagementConfiguration.Read.All DeviceManagementServiceConfig.Read.All User.Read
  3. Copia el Application (client) ID y el Directory (tenant) ID de la página Overview.
  4. Pégalos aquí al lado, guarda y pulsa Conectar a Intune. Todo corre en tu navegador; ningún dato sale a terceros.
Usa common sólo si la app es multi-tenant.
